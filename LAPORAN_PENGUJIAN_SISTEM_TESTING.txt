1. PENDAHULUAN DAN METODOLOGI PENGUJIAN
--------------------------------------------------------------------------------
Pengujian perangkat lunak ini dilakukan secara terotomatisasi (Automated Testing)
sebagai bagian dari tahapan Quality Assurance (QA) sebelum sistem dideploy ke
lingkungan produksi (Production Hosting).

Pengujian mencakup 3 (tiga) tingkatan pengujian utama:
1. Unit Testing:
   Pengujian pada komponen terkecil (fungsi, helper, model, enum status, dan
   aturan logika bisnis) tanpa dependensi eksternal.
2. Feature / Integration Testing:
   Pengujian alur bisnis menyeluruh, termasuk autentikasi (login, register,
   OAuth Google, OTP), manajemen keuangan saldo & withdraw, komunikasi chat,
   sistem pemesanan order, pelaporan pelanggaran, dan perhitungan tarif.
3. Smoke / Page Access Testing:
   Pengujian aksesibilitas seluruh halaman antarmuka (UI) untuk memastikan tidak
   ada error HTTP 500, broken view/template, atau kebocoran otorisasi pada setiap
   hak akses pengguna (Customer, Mitra, Admin Wilayah, dan Super Admin).

5. VERIFIKASI KEAMANAN & PENGATURAN DEPLOYMENT (PRODUCTION CHECKLIST)
================================================================================
Selain pengujian fungsional di atas, pengujian konfigurasi lingkungan telah
diverifikasi dengan hasil sebagai berikut:

1. Penonaktifan Fitur Testing:
   - Nilai DEMO_LOGIN disetel ke FALSE: Kartu akun demo pada halaman login
     otomatis tidak dimuat di antarmuka publik.
   - Nilai GPS_SIMULATOR disetel ke FALSE: Tombol dan antarmuka simulator
     lokasi palsu disembunyikan dari aplikasi.

2. Aset Antarmuka (Vite Production Build):
   - Perintah `npm run build` sukses menghasilkan bundel aset produksi di
     folder `public/build/` dengan ukuran terkompresi Gzip yang optimal.

3. Kesiapan Cache Laravel:
   - `php artisan config:cache` : Berhasil tanpa closure error.
   - `php artisan route:cache`  : Berhasil tanpa route duplicate/conflict.
   - `php artisan view:cache`   : Berhasil 100% tanpa sintaks error Blade.

4. Audit Kode Bersih:
   - Seluruh baris kode bebas dari fungsi penahan eksekusi `dd()`, `dump()`,
     atau `var_dump()` yang berpotensi membocorkan data sensitif.
